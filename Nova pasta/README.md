# Portfólio profissional — single page

Estrutura:
- `index.html` — conteúdo e estrutura semântica da página
- `css/style.css` — identidade visual, layout e responsividade
- `js/script.js` — menu mobile, scroll/âncoras, animações e formulário demonstrativo

## Como personalizar
1. Abra `index.html`.
2. Substitua `Seu Nome`, profissão, textos e placeholders pelos seus dados.
3. Troque os links `#` dos projetos e redes sociais pelos endereços reais.
4. Substitua o bloco "Sua foto" por uma `<img>` quando tiver sua foto.
5. Edite as habilidades, experiências e projetos.
6. Para o formulário realmente enviar mensagens, conecte-o a um serviço de formulários ou backend.

## Navegação
As âncoras usadas são:
`#inicio`, `#sobre`, `#habilidades`, `#projetos`, `#experiencia`, `#contato`.

Não há páginas HTML adicionais: todo o portfólio está em uma única página vertical.
